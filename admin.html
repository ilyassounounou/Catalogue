Panneau d'administration

Connectez-vous à votre dépôt GitHub pour gérer le catalogue.

Comment créer un jeton d'accès ?
  1. Allez sur GitHub → photo de profil → Settings.
  2. Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Limitez-le à ce seul dépôt (Only select repositories).
  4. Dans Permissions → Repository permissions → mettez Contents: Read and write.
  5. Générez, copiez le jeton et collez-le ci-dessus. Il n'est jamais enregistré ni envoyé ailleurs qu'à GitHub, et il est effacé si vous fermez cet onglet.

⚠️ Ne partagez jamais ce jeton et ne laissez pas ce lien admin.html accessible publiquement (ne le mettez pas dans vos menus de navigation).
